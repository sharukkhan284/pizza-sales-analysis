# Pizza Sales Performance Analysis

## Project Overview
Analyzed pizza sales data for January–December 2015 to understand revenue trends, pizza category performance, and top-performing pizzas.

## Tools Used
- **Excel:** Data cleaning, PivotTables, charts, and dashboard
- **MySQL:** SQL queries, joins, and sales analysis
- **Power BI:** Interactive dashboard and KPI visualization
- **GitHub:** Project portfolio and documentation

## Key Performance Indicators
- **Total Revenue:** 817,860.05
- **Total Pizza Quantity Sold:** Approximately 50K
- **Order Records:** 21,350
- **Average Order Value:** 38.31

## Key Findings
- Classic pizzas generated the highest revenue by category.
- The Thai Chicken Pizza was the top pizza by revenue.
- Monthly revenue fluctuated throughout 2015, peaking around July.
